# Security policy

This repository is a **defensive, educational** toolkit.

## Authorized use only

Use these tools only on:

- your own source code, logs, and hosts
- systems you have **written authorization** to assess

Do not use this project to scan, attack, or probe third-party systems.

## What this project will never include

- exploit payloads or exploit generators
- unauthenticated remote scanners aimed at arbitrary hosts
- credential stuffing, brute force, or malware samples

## Reporting issues

Open a GitHub issue describing the problem. Do not attach real secrets or customer data.
